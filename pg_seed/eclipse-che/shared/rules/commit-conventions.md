# Commit Conventions — All Eclipse Che Subprojects

Unified commit message rules for all subprojects in the Eclipse Che ecosystem.

---

## Format

```
type(scope): short description

Optional body — explain WHY, not what (the diff shows what).

Closes #NNNN

Assisted-by: {AGENT_NAME}
Signed-off-by: {AUTHOR_NAME} <{AUTHOR_EMAIL}>
```

### Rules

- **Subject line ≤ 50 characters**
- **Subject: lowercase after the colon** — `fix(ui): prevent overflow` not `Fix(UI): Prevent Overflow`
- **Imperative mood**: "add", "fix", "remove" — not "added", "fixed", "removes"
- **No period** at the end of the subject line
- **Body is optional** — only when the why is non-obvious
- **Issue reference**: `Closes #NNNN` on its own line in the body (not in subject)

---

## Commit Types

| Type | When to use |
|---|---|
| `fix` | Bug fix |
| `feat` | New feature or behavior |
| `chore` | Maintenance: deps, version bumps, config, CI |
| `refactor` | Code restructuring — no behavior change |
| `test` | Adding or updating tests only |
| `docs` | Documentation only |
| `build` | Build system changes (Dockerfile, Makefile, webpack) |
| `ci` | CI/CD workflow changes |

## Trailers

**Required:**
```
Assisted-by: Claude Sonnet 4.6
```

**Optional:**
```
Signed-off-by: Jane Developer <jane@example.com>
```

**Forbidden — NEVER add these:**
```
Made-with: Claude
Co-authored-by: claude[bot] <...>
```

## Examples

```
fix(workspace): prevent duplicate startup PATCHes

Closes #23892

Assisted-by: Claude Sonnet 4.6
Signed-off-by: Oleksii Orel <oorel@redhat.com>
```

```
chore(deps): bump axios from 1.15.2 to 1.16.1

Fixes CVE-2025-XXXX.

Assisted-by: Claude Sonnet 4.6
```

```
feat(oauth): expose clientId in OAuthAuthenticatorDescriptor

Assisted-by: Claude Sonnet 4.6
```

---

## No AI Comments in Source Code

Do not add comments like:
- `// Generated by Claude`
- `// AI-generated`
- `// Added by assistant`

The `Assisted-by:` trailer in the commit message is the only required AI attribution.
